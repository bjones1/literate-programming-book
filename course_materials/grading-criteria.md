# Grading rubrics

Grade the Git hints homework in @ideas.md using the rubric and grading rules
below. Write the results to `grades.md`.

## Rubric

From the
[class assignment](https://canvas.msstate.edu/courses/186065/assignments/1839505):

Contribute to the design of the Git hints tool by committing the following to
the git-tool branch of
https://github.com/bjones1/literate-programming-fall-2024, then pushing your
commits.

- (25 points) Add at least two hints, including the condition needed to trigger
  a hint, to the requirements, under "The tool should offer hints in the
  following categories:".
- (25 points) Add a git command to the implementation, under "Determining
  git/repo conditions:", that determines at least one git/repo condition from
  the Requirements section.
- (25 points) Add at least one item to the personal experience section.
- (25 points) Review the document using an LLM. Make 5 improvements based on
  carefully considering LLM output.

Sign all items with your net id, for example "(bj147)" for grading purposes.

## Grading rules

- Scope: grade all commits on the `git-tool` branch.
- Due date: 2026-Sep-27. Note any commit made after the due date in `notes`.
- Attribution: credit an item to a student only if it is signed with their
  netid. Unsigned items earn no credit.
- Hints: \[12.5 points per hint, maximum 2 hints\]. A hint without a triggering
  condition earns \[0\]. Items under Definitions and How to (such as `--help`
  commands) count as hints.
- Git command: \[25\] if the command actually detects a condition from the
  Requirements section; \[10\] if the command is vague, incorrect, or doesn't
  detect a condition.
- Personal experience: \[all or nothing\].
- LLM review: \[5 points per distinct improvement, maximum 5 improvements\],
  judged from the student's commits. Typo fixes, edits to other students' text
  count, and a "clarified by" signature counts as an improvement by that
  student. If a student has no identifiable LLM-review changes, give \[0\] and
  say so in `notes`.
- Roster: Exclude bj147 (the instructor).
